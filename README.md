## Como instalar

1. Clique no botão verde **Baixar para Windows**. O download começa sozinho.
2. Abra o arquivo **TapMe-Setup-2.0.9.exe**, que fica na pasta **Downloads**.
3. Se aparecer a tela azul **"O Windows protegeu o computador"**, clique em **Mais informações** e depois em **Executar assim mesmo**.
4. Siga a instalação e abra o TapMe.

> **Por que esse aviso aparece?** O Windows mostra essa tela para programas sem certificado digital pago, como é o caso do TapMe. Baixe sempre por este botão, para ter certeza de que o arquivo é o original.
